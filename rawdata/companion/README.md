# companion

Unmodified copies of raw data and model tables from the companion study (Rivera-Rincón et al. 2026), from [StevisonLab/Combination-effects-of-hypoxia-and-low-temperature-in-Drosophila](https://github.com/StevisonLab/Combination-effects-of-hypoxia-and-low-temperature-in-Drosophila). We include them so that `scripts/sex_ratio.R` and `scripts/companion_summary.R` run from this repository alone.

| File | Contents |
|---|---|
| `F1_Crosses.csv` | F1 crosses: treatment, DGRP line, number of parents, F1 cross vial number |
| `F1_Virgin_Collections.csv` | F1 virgin collections, linking collection vials to F1 crosses |
| `F1_Fecundity_Dup_rem.csv` | F1 offspring counts by sex and day |
| `Weight.csv` | Body mass of F1 adults |
| `CTmax.csv` | Critical thermal maximum of F1 adults |
| `RQ.csv` | Respirometry (VCO<sub>2</sub>, VO<sub>2</sub>) of F1 adults |
| `Ovarioles.csv` | Oocyte and TUNEL-positive cell counts by ovary and stage |
| `model_tables/*.csv` | The companion study's model tables (`output/` in that repository) |
